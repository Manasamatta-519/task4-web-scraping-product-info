# SkillCraft Technology Internship — Task 4

## Project
Web scraping product information from the Books to Scrape practice website and saving it in CSV format.

## Features
- Extracts product names, prices, ratings, availability, and product links.
- Follows the site's pagination.
- Saves results to `products.csv`.

## Requirements
- Python 3.9 or newer recommended
- Internet connection

## Installation
Open a terminal in this folder and run:

```bash
python -m pip install requests beautifulsoup4
```

## Run the scraper
```bash
python scraper.py
```

The script creates `products.csv` in the same folder. The CSV contains the results collected when you run the script. `sample_products.csv` is only an example of the output format; it is not generated by the scraper run.

## Libraries used
- `requests`: downloads webpage HTML
- `BeautifulSoup` from `bs4`: parses HTML
- `csv`: writes product data to CSV (built into Python)
- `time` and `urllib.parse`: small delay and URL handling (built into Python)

## Important
Use this educational practice site and follow the site's usage guidance. Do not scrape private data, bypass access controls, or overload websites.
